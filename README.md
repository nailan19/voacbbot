# Vocabulary Coach

A small interactive web app for English learners. Type in a word and get its definitions, collocations, and example sentences, generated by Claude. If a word has multiple meanings, each meaning gets its own definition, collocations, and 2-3 example sentences (each at least 10 words long). The search bar stays available after every lookup so you can keep entering new words.

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```
2. Copy `.env.example` to `.env` and set your Anthropic API key:
   ```bash
   cp .env.example .env
   ```
3. Start the server:
   ```bash
   npm start
   ```
4. Open `http://localhost:3000` in your browser.

## How it works

- The frontend (`public/`) is a single page with a search bar and a results dashboard.
- Each submitted word is sent to `POST /api/word`, which asks Claude (`claude-opus-5`) for a structured response (definitions, collocations, examples per meaning) validated against a schema, and returns it as JSON.
- New lookups are prepended to the results list without reloading the page.
